# ✦ Mis Quince Andrea — Invitación digital V2

Versión mejorada para GitHub Pages.

## Incluye
- Portada de sobre animada con botón **Abrir invitación**.
- Cuenta regresiva.
- Luciérnagas, pétalos y efectos suaves.
- Música opcional.
- Galería con ventana ampliada.
- Confirmación por WhatsApp.
- Botón para compartir.
- Animaciones al desplazarse.
- Diseño responsive para celular y computador.

## Personalizar

### Fecha y hora
En `script.js`:
`const eventDate=new Date("2026-10-25T19:00:00");`

### WhatsApp
En `index.html`, cambia `573000000000` por el número real.

### Lugar y mapa
Cambia el texto del lugar y el enlace de Google Maps.

### Fotos
Reemplaza las tarjetas de la sección Galería por las fotos de Andrea. La primera usa la imagen de referencia incluida en `assets/referencia-princesa.png`.

### Música
Coloca un archivo llamado `assets/musica.mp3`. El navegador permitirá reproducirlo después de que el visitante pulse un botón.

## GitHub Pages
1. Crea un repositorio, por ejemplo `mis-quince-andrea`.
2. Sube `index.html`, `styles.css`, `script.js` y la carpeta `assets`.
3. Ve a **Settings → Pages**.
4. Selecciona **Deploy from a branch**.
5. Selecciona `main` y `/ (root)`.
6. Guarda.

La URL será similar a `https://TU-USUARIO.github.io/mis-quince-andrea/`.
